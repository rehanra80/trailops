## Core Service Tiers

### 1. Automation Strategy & System Audit
- **Target Audience**: Companies with manual operational bottlenecks or seeking to replace high-cost Zapier/Make accounts.
- **Timeline**: 2 to 4 business days
- **Scope & Deliverables**:
  - Full operational workflow mapping & bottleneck identification
  - Cost-benefit and ROI analysis (SaaS task fee reduction)
  - Prioritized engineering backlog & architecture blueprint
  - Fixed-price build roadmap for implementation
- **Typical Investment**: $500 – $1,500 (Credited toward build engagement if executed by TrailOps)

---

### 2. Single Workflow / Pipeline Automation
- **Target Audience**: Teams needing a mission-critical automated pipeline (e.g. Lead routing, multi-system CRM sync, webhook ingestion, transactional notifications).
- **Execution Engine**: n8n (Self-hosted or Cloud), Zapier, Make, custom Node/Python microservice
- **Timeline**: 3 to 7 business days
- **Scope & Deliverables**:
  - End-to-end pipeline build with error-handling and fallback retries
  - Webhook & API key security configuration
  - Bi-directional sync across tools (HubSpot, Salesforce, Airtable, PostgreSQL, Slack, etc.)
  - 14-day post-launch warranty and runbook documentation
- **Typical Investment**: $1,200 – $3,500 (One-time, fixed scope)

### 3. AI Integration & Custom Agent Deployment
- **Target Audience**: Businesses adding LLM capabilities, intelligent document processing, RAG pipelines, or autonomous customer support agents into their tech stack.
- **Supported Models**: OpenAI GPT-4o, Anthropic Claude 3.5 Sonnet, Google Gemini 1.5 Pro / 2.0, Self-hosted Ollama / Llama 3
- **Timeline**: 1 to 3 weeks
- **Scope & Deliverables**:
  - Custom RAG knowledge retrieval architecture (Vector DB / Supabase pgvector)
  - System prompt engineering, guardrails, and deterministic fallback logic
  - Webhook / API agent wiring (Slack, Web chat, CRM, internal dashboard)
  - Admin observability and token usage monitoring
- **Typical Investment**: $2,500 – $7,500 (One-time, fixed scope)
