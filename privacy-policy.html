Privacy Policy & Data Security

LAST UPDATED: 2026-07-21 // VERSION 2.4

// 01 DATA COLLECTION & USE

TrailOps Systems collects minimal contact information (name, work email, project details) provided voluntarily through audit request forms. This data is strictly utilized to communicate system specifications and quote project deliverables.

// 02 PROPRIETARY SOURCE CODE OWNERSHIP

All code, architecture scripts, vector configurations, and webhooks developed during engagements belong 100% to the client upon project completion and handover. TrailOps does not retain or resell proprietary client IP.

// 03 THIRD-PARTY INTEGRATIONS

Our services integrate with third-party APIs (OpenAI, Anthropic, Google, Stripe, Supabase, Meta Graph API). Client data processed through these endpoints is subject to their respective security models. We configure enterprise privacy flags (e.g., zero data retention for LLM training) wherever supported.
