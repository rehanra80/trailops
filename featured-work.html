AI-Powered LinkedIn Content

LinkGrow

A LinkedIn content tool that turns a rough idea into a polished post using proven copywriting frameworks. React/TypeScript frontend with an Express backend that proxies Gemini calls server-side, so API keys never touch the browser.

Built a production prompt library covering the top 10 LinkedIn post frameworks (AIDA and others), designed with {{double_brace}} variable syntax so the same prompts drop straight into n8n pipelines without rewriting.

Multi-Tenant SaaS

Flipbook SaaS

A Flipsnack-inspired platform where anyone can upload a PDF and get an instant, shareable digital flipbook with a real page-curl effect — built with CSS 3D transforms and PDF.js, not a canned embed.

Multi-tenant from the ground up on Next.js App Router and Supabase, with per-flipbook custom branding and public share links out of the box.

Automation Pipeline

Multi-Channel Content Publisher

An n8n pipeline that pulls from RSS, summarizes with a self-hosted Ollama model, generates cover art with Pollinations.AI (free, no API key), and publishes simultaneously to WordPress, Facebook, Instagram, LinkedIn, Telegram, and Discord.

Zero per-generation cost on the AI side — one workflow run replaces a full afternoon of manual cross-posting.
